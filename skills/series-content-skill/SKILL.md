# 笔记成文与公众号排版

## 范围

从用户提供的笔记、摘录、草稿或指定参考资料出发，按要求整理结构、润色表达、选版式、输出文章或公众号 HTML。支持读书、课程、工作、知识分享和系列写作，输入不必遵循固定格式。

匹配用户要求的阶段：只要排版时保留正文；只要提纲或审校时交付对应内容；要求成稿时完成文章；要求 HTML 时交付可用文件。不默认扩写经历或改变立场。

## 写作与排版

- 依据读者、用途和已有语气整理；缺少信息时只询问会影响结果的事项，常规选择可自行处理。
- 先确定内容结构，再调整视觉层次。小标题使用自然中文，表达真实的内容关系。
- 有用户确认的样式时复用；未指定时依据文章长度、结构推荐适合的版式。
- HTML 起点：[精简编辑版模板](templates/clinical-editorial.html)。使用前阅读 [版式规则](references/clinical-editorial.md)，按主题替换系列标签、词条结构、品牌和关注文案；普通文章不强制添加医学标签、音标或例句。
- 系列写作保留已确认的命名、品牌、标题层级和结尾规则；不覆盖已发布旧篇。
- 在正文外提供富文本复制按钮，复制 text/html 与 text/plain，并提供手动复制回退。正文内联样式，单栏最大680px，系统字体，少用重复边框。
- 输出文件中的图片路径必须可用；说明本地复制不保证图片自动上传。正文、标题、作者、摘要与封面在公众号后台分别处理。
- 发布由用户在公众号后台完成；生成 HTML 不等于已经发布或完成微信双模式验证。

## 事实与来源

保留用户观点，不编造事实、数据、经历或引文。专业判断按需查证原始可靠来源；引用紧跟对应段落，文末提供可查的原始链接。明确区分引用、转述和新写示例。

语言学习类内容可按需补充词义、发音、搭配和例句；医疗剧等专业主题的说明需要核查，不能用剧情代替专业依据。其他主题不强制采用学习词条结构。

## 案例与资源

The Pitt 医学英语文章只是一个实际案例，其医学内容、用户品牌与剧集字段不作为通用默认。The Pitt 后续文章使用2026-11-18确认的精简版；其他主题据用户选择适配。

- [编辑流程](references/editorial-workflow.md)：笔记整理、写作与公众号交付。
- [Clinical Editorial 版式规则](references/clinical-editorial.md)：已确认的具体系列样式。
- [可复制 HTML](templates/clinical-editorial.html)：自包含的结构与复制功能。
- 仓库 examples 中的旧文章及生成器只作历史案例。独立安装本 Skill 文件夹后，不依赖 examples 也能从内置模板生成 HTML。

小测试、资料领取、广告占位和其他衍生物仅在用户要求时加入。未提供公众号名称时，不默认使用 ActiveReading。
