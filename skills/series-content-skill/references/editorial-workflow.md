# 剧集英语编辑工作流

本流程支持不同剧集和影视作品。仓库中的 The Pitt 文章、术语与生成器只作为一个实际案例；开始处理其他作品时，使用用户提供的素材，不默认套用医学语境或案例事实。

## 1. 接收素材

确认作品/集数/场景（如有）、目标读者、交付形式和素材状态。用户的记录可以是原句、听写大意、表达、词语或问题，格式不限。优先处理用户指定的条目；不要声称自动看过视频或拿到了未提供的字幕。

## 2. 整理条目

逐条解释场景含义、语气和语言用法。按需要补充术语、缩写、发音、搭配、中文说明和教学例句。区分剧中原句、用户听写、转述和新写例句。无法确认的台词标「待核实」。涉及专业背景时查可靠来源；医学背景不能以剧情代替临床指南。

## 3. 规划或写作

先根据用户目标确定范围：只要规划就交付选题角度、背景要点、提纲和待核实事项；要求成文时，再把已整理条目组织成适合目标读者的文章。可以使用“场景背景 → 表达讲解 → 用法辨析/例句 → 回顾”的顺序，也可按素材调整，不固定篇幅与模块。

## 4. 生成公众号稿

本仓库的 `pitt_t07_layout.py` 与 `build-the-pitt-*.py` 是 The Pitt 医学英语系列的示例实现。仅在制作 The Pitt 相关示例时按需复用；处理其他剧集时，确认版式和数据结构合适后再适配，不能把医学词条或特定剧集字段当成通用要求。公众号 HTML 应提供「复制排版内容」按钮，并与正文源文件保持一致。

## 5. 检查与交付

检查素材状态、解释是否贴合场景、术语与翻译、原句和例句的区分、结构、HTML 输出与链接。按要求报告创建或修改的文件、生成方法和待核实事项。没有实际在公众号编辑器中粘贴测试，不宣称通过粘贴或深色模式验证。

## 微信公众号后台

若交付 HTML，说明用户可打开文件并点击「复制排版内容」，登录 [微信公众平台](https://mp.weixin.qq.com/)，新建图文后粘贴正文；标题、作者、摘要和封面分别填写。预览后可保存草稿，准备好时再发布。复制正文不会自动填写这些字段或上传封面。
