# 从笔记到公众号文章

## 接收与整理

以用户提供的读书摘录、课程记录、工作笔记、知识素材或草稿为基础。确认实际需要：梳理笔记、写提纲、润色、成稿或仅排版。根据材料推断读者和语气；关键缺口才提问。

合并重复内容、提炼主题、安排阅读顺序。保留用户立场、经历和已经确认的正文；补写内容不冒充引用或真实经历。

## 写作

用自然中文的小标题和段落组织内容。引用、数据和专业说明按需核查。语言学习任务才补充词义、音标、译文和教学例句。普通文章不强制使用词条、测验或医学背景。

## 排版

优先复用用户选定的样式。使用内置 templates/clinical-editorial.html 时，按 references/clinical-editorial.md 的视觉规则调整，替换品牌、标题、模块和结尾。The Pitt examples 只作案例；单独安装的 Skill 不依赖这些外部案例运行。

生成单栏、内联样式的 HTML，复制按钮放在正文外。HTML与原稿内容一致，图片来源和路径可查。参考编号贴近文段，文末列原始链接。

## 交付

给出文件链接与简短使用方法。打开 HTML → 点击复制 → 公众号后台新建图文并粘贴 → 分别填写标题、作者、封面和摘要 → 上传图片并检查手机预览 → 用户保存草稿或发布。没有完成微信浅色/深色粘贴测试时如实说明。

衍生资料、广告、测试题和关键词领取按用户当篇要求加入。
