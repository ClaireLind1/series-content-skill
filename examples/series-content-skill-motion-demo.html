写《匹兹堡医护前线》医学英语系列时，我会先记下台词、表达和疑问，再查语境、整理成文。我把这套做法整理成了自己的开源项目 series-content-skill。读书摘录、课程记录、工作心得和已有草稿也可以用它整理。

可以从这句开始

用 series-content-skill，把这份读书笔记整理成公众号文章，生成带复制按钮的 HTML。

01 / 下载 Skill

项目下载入口
↗ 打开 GitHub 仓库
https://github.com/ClaireLind1/series-content-skill
打开仓库，点击绿色 Code 按钮，选择 Download ZIP，下载后解压。若微信内打不开 GitHub，可复制地址到电脑浏览器访问。

02 / 安装到 AI 工具

解压后，进入项目里的 skills/series-content-skill，确认里面有 SKILL.md。复制整个 series-content-skill 文件夹，放到你所用工具的用户级 skills 目录。

Codex：~/.agents/skills/
Claude Code：~/.claude/skills/
Cursor：~/.cursor/skills/
~ 表示用户主目录。Windows 可从 %USERPROFILE% 进入。目录不存在时可以新建。

确认最终路径以 series-content-skill/SKILL.md 结尾，再重启或重新打开工具。

03 / 从一份笔记开始

用 series-content-skill，把下面的读书笔记整理成一篇公众号文章。先梳理结构，再润色表达。保留我的观点，拿不准的事实标出来。最后生成带复制按钮的 HTML。

我的笔记：[在这里粘贴]

Codex 可以输入 $series-content-skill 调用。已有定稿也可以直接说「正文不改，按选好的样式排版，给我可复制到公众号的 HTML」。

想省一步
把笔记交给 series-content-skill，说「帮我整理成公众号文章，选一个合适的样式，生成带复制按钮的 HTML」。

想自己选
选好样式后，把样式名和正文一起发给 AI。例如「用 series-content-skill，正文不改，按天空蓝 × 奶油黄排版，生成公众号 HTML」。

05 / 复制到公众号

用浏览器打开生成的 HTML，点击「复制到微信公众号」，在公众号后台新建图文并粘贴正文。标题和封面在后台填写，图片按需上传。先发手机预览，确认后再发布。
