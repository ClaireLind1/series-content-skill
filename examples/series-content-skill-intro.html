SERIES-CONTENT-SKILL · 项目介绍

我把看剧笔记，做成了一个能生成公众号文章的 AI Skill

前言

写《匹兹堡医护前线》（The Pitt）系列时，我会在看剧时记下英文台词、表达和疑问，之后再查语境和术语、解释表达、组织文章并处理公众号排版。

我把这套实际使用的流程整理成开源 Agent Skill：series-content-skill。它不是独立软件，而是一套可安装到 Codex、Claude Code 或 Cursor 等 AI Agent 的工作指令：你提供笔记和要求，AI 按流程帮你整理、写作或审校。项目已发布在 GitHub，可下载，也可以按需修改。

从你记下的内容开始

这一步由你来决定。可以记下没听懂的台词，也可以是觉得值得学的表达、一个术语、一句听到的大意，或者一个想弄明白的问题。格式不用统一；有原句就给原句，只有听写或大意，也可以注明目前不确定。

它不会自动观看整集、替你挑台词，也不会把听不清的内容补成确定的原话。素材由你选择，拿不准的部分会标出来供你核对。

这个 Skill 能帮你做什么

• 逐条整理笔记：结合你提供的台词、听写或问题解释场景含义；补充专业术语、缩写、发音、常见搭配、中文说明和教学例句。

• 整理成文章：把已经核对过的内容按主题和阅读顺序组织起来；也可以只生成词条清单或文章提纲。

• 检查和修改草稿：帮你检查术语、语境、翻译和结构，并按你的意见修订。

• 生成公众号排版稿：输出 Markdown；有可用的排版模板或生成器时，再生成可复制正文的 HTML。本项目附有 The Pitt 案例的版式脚本和 HTML 演示。

原句、听写大意、转述和教学例句会区分处理；不能确认的内容标注待核实。你可以只要求其中一项，也可以从笔记整理一路做到公众号文章；需要排版 HTML 时，配合相应模板或生成器即可。

从 HTML 到公众号文章

在文章 HTML 中点击「复制排版内容」，粘贴到公众号后台新建图文的正文区，再填写标题、作者、摘要和封面。要让读者跳转 GitHub，把仓库地址设为图文的「阅读原文」链接。预览确认后，就可以保存草稿或发布。

已发布的真实案例

The Pitt 第一集的医学英语系列已经整理到 17 篇。下面是其中三篇已发布文章：

• 第 1 篇｜开场与口语

• 第 9 篇｜鉴别诊断与收治

• 第 17 篇｜呕吐与误食

这个 Skill 叫 series-content-skill，The Pitt 是它的真实案例，不是唯一题材。其他剧集或影视作品中，你自己挑出的英文表达、听写、疑问和笔记，也可以用同样的流程整理、成文、审稿或排版。
